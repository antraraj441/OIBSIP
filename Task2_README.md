# Task 2 – E-commerce Customer Segmentation

## Objective

To segment e-commerce customers based on their purchasing behavior and identify different customer groups for targeted marketing.

## Tools Used

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Seaborn
* Google Colab

## Work Done

* Loaded and inspected the customer transaction dataset.
* Cleaned and prepared the data.
* Calculated **Recency, Frequency, and Monetary (RFM)** values.
* Standardized the features using StandardScaler.
* Applied **K-Means Clustering**.
* Used the **Elbow Method** to determine the number of clusters.
* Visualized the customer segments.
* Analyzed the characteristics of each cluster.
* Suggested suitable marketing strategies for different customer groups.

## Key Insights

The clustering analysis identified different customer segments based on their purchasing frequency, recency, and monetary value. These segments can help businesses understand customer behavior and create targeted marketing strategies.

## Conclusion

Customer segmentation helps businesses identify valuable customers, inactive customers, and different purchasing patterns. This analysis can support more personalized marketing and customer-retention strategies.
