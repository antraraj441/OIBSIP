# Retail Sales EDA 📊

This project is about exploring a retail sales dataset using Python to understand **sales trends, customer behaviour, and product performance**.

### What I analyzed

* Dataset structure and missing values
* Basic statistics
* Monthly and quarterly sales trends
* Customer age and gender
* Top 10 best-selling products
* Revenue by product category
* Correlation between numerical variables
* Additional visual insights

### Tools Used

Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

### Key Goal

The main goal is to turn raw sales data into useful insights that can help with **better marketing, inventory management, and business decisions**.
